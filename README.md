# 世界地図ビューア (world-viewer)

創作世界を表示するためのスマートフォン向けWeb地図アプリです。

現在のバージョン: **Version 0.3**

- 表示できる世界: 「過速世界」のみ（仮のデータ）
- できること:
  - 地球を指で回す・拡大縮小する・平面地図(2D)と地球儀(3D)の切り替え
  - 画面下の4つのボタンで「3D地球儀・平面地図・北極・南極」を切り替え
    - 北極・南極は専用の地図（極を中心にした特殊な描き方）で表示するため、
      3D地球儀モードで起きていた極地特有の模様の乱れが起きません
  - 年代スライダー（12世紀〜現在、20年刻み）で、その時代の勢力図・国境を表示（3D地球儀・平面地図モードのみ）
  - その時代の主要都市（首都・副首都・第3都市）の表示/非表示切り替え
  - 「地形図」モードへの切替（水中・海底の地形も含む）と、氷河表示の切替（全モード共通）
- 対応端末: Android の Google Chrome（Pixel 7a で確認）
- 注意: 勢力図・都市・氷河のデータはすべて仮のものです。過速世界の実際の設定ができ次第、差し替えます。北極・南極の地形の色が本当に正しく出るかは、この端末（開発用のサーバー）からは確認できておらず、実機での確認が必要です。

## スマートフォンで見る方法

GitHub Pages（無料のホームページ公開機能）を使います。設定は最初の1回だけです。

1. このリポジトリの **Settings**（設定）を開く
2. 左メニューの **Pages** を開く
3. 「Build and deployment」の **Branch** で、`claude/map-app-v0-1-az6aoa` ブランチと `/ (root)` を選び、**Save** を押す
4. 数分待ってから、表示されるURL（`https://gusk2020.github.io/world-viewer/` の形式）をPixel 7aのChromeで開く
