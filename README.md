# 世界地図ビューア (world-viewer)

創作世界を表示するためのスマートフォン向けWeb地図アプリです。

現在のバージョン: **Three.js版 Version 0.1**（設計をゼロからやり直し）

- 表示できる世界: 「過速世界」のみ（仮のデータ）
- できること:
  - 3Dの地球を指で回す・拡大縮小する（ピンチ操作）
  - 北極点・南極点を真上から見ても、黒い穴や継ぎ目がない完全な球体
- 対応端末: Android の Google Chrome（Pixel 7a で確認予定）
- 今回のやり直しについて:
  - これまでのMapLibre／CesiumJSという地図の仕組みでは、北極・南極付近の表示問題が何度直しても残ってしまいました。
  - 今回、Three.jsという別の仕組みに全面的に作り直しました。地図を細かいマス目（タイル）に分けて貼り合わせる方式をやめ、地球全体を1枚の画像として球に貼る、より単純で確実な方法にしています。
  - 実際に北極点・南極点を真上から描画して、黒い部分がないことを確認済みです。
  - 古いMapLibre／CesiumJS版は削除せず、`legacy-cesium-maplibre-v0` というブランチに保存してあります。いつでも元に戻せます。
- 注意:
  - 地表の画像は、過速世界の実際の地形ではなく、実際の地球の衛星写真（仮）です。過速世界の本当の地図ができ次第、差し替えます。
  - Version 0.1では、地形の凹凸・都市・国境・2D地図はまだありません。まずは「黒い穴のない3D地球」だけを確実に完成させる段階です。
  - 今後、OpenLayersによる2D地図（V0.2）、3D/2D切替（V0.3）、標高データによる地形（V0.4）、海面上昇機能（V0.5）、都市・国境などの過速世界データ（V0.6以降）の順に、1段階ずつ進めていきます。

## スマートフォンで見る方法

GitHub Pages（無料のホームページ公開機能）を使います。設定は最初の1回だけです。

1. このリポジトリの **Settings**（設定）を開く
2. 左メニューの **Pages** を開く
3. 「Build and deployment」の **Branch** で、`claude/map-app-v0-1-az6aoa` ブランチと `/ (root)` を選び、**Save** を押す
4. 数分待ってから、表示されるURL（`https://gusk2020.github.io/world-viewer/` の形式）をPixel 7aのChromeで開く
