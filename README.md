# 世界地図ビューア (world-viewer)

創作世界を表示するためのスマートフォン向けWeb地図アプリです。

現在のバージョン: **Three.js版 Version 0.2**

- 表示できる世界: 「過速世界」のみ（仮のデータ）
- できること:
  - 3Dの地球を指で回す・拡大縮小する（ピンチ操作）※確認済み
  - 北極点・南極点を真上から見ても、黒い穴や継ぎ目がない完全な球体 ※確認済み
  - 2Dの世界地図（OpenLayers）※今回追加。3Dとはまだ別ページで、切替はできません
- 対応端末: Android の Google Chrome（Pixel 7a で確認済み）
- 注意:
  - 地表の画像・2D地図は、過速世界の実際の地形ではなく、実際の地球の写真・地図（仮）です。過速世界の本当の地図ができ次第、差し替えます。
  - 2D地図は普通のWeb地図と同じ理由で、北極点・南極点そのものは地図の端で切れます（3Dの黒い穴とは別の、ふつうの地図の仕組み上の制限で、問題ではありません）。
  - 今後、3D/2D切替（V0.3）、標高データによる地形（V0.4）、海面上昇機能（V0.5）、都市・国境などの過速世界データ（V0.6以降）の順に、1段階ずつ進めていきます。
  - 古いMapLibre／CesiumJS版は削除せず、`legacy-cesium-maplibre-v0` というブランチに保存してあります。いつでも元に戻せます。

## スマートフォンで見る方法

GitHub Pages（無料のホームページ公開機能）を使います。設定は最初の1回だけです。

1. このリポジトリの **Settings**（設定）を開く
2. 左メニューの **Pages** を開く
3. 「Build and deployment」の **Branch** で、`claude/map-app-v0-1-az6aoa` ブランチと `/ (root)` を選び、**Save** を押す
4. 数分待ってから、表示されるURL（`https://gusk2020.github.io/world-viewer/` の形式）をPixel 7aのChromeで開く
   - 3D地球儀: そのままのURL（`index.html`）
   - 2D地図: URLの末尾に `map2d.html` を付けて開く（例: `https://gusk2020.github.io/world-viewer/map2d.html`）
