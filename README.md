# 世界地図ビューア (world-viewer)

創作世界を表示するためのスマートフォン向けWeb地図アプリです。

現在のバージョン: **Cesium版 Version 0.1**（地図表示の仕組みをCesiumJSに全面切替）

- 表示できる世界: 「過速世界」のみ（仮のデータ）
- できること:
  - 3Dの地球を指で回す・拡大縮小する
  - 右上のボタンで3D/2D表示を切り替え
  - 地形（陸地の高さ・海の深さ）を、極地も含めてきれいに表示
    - これまでのMapLibreという地図の仕組みでは、北極・南極付近で表示が崩れる問題がありました。
      今回、地図の土台をCesiumJSという別の仕組みに変更し、この問題の根本的な解決を試みています。
  - 年代スライダー（12世紀〜現在、20年刻み）で、その時代の勢力図・国境を表示
  - その時代の主要都市（首都・副首都・第3都市）の表示/非表示切り替え
  - 「地形図」モードへの切替（歴史地図と地形図の表示切替）と、氷河表示の切替
- 対応端末: Android の Google Chrome（Pixel 7a で確認）
- 注意:
  - 勢力図・都市・氷河のデータはまだ仮のものです。過速世界の実際の設定ができ次第、差し替えます。
  - 今回は「地形が世界全体・極地まで含めてきれいに表示できるか」を最優先で確認する段階です。海面上昇のシミュレーターはまだ次の段階です。
  - 地形・地図データの取得先の設定を一部推測で決めた箇所があり、実機で正しく表示されるか確認が必要です。

## スマートフォンで見る方法

GitHub Pages（無料のホームページ公開機能）を使います。設定は最初の1回だけです。

1. このリポジトリの **Settings**（設定）を開く
2. 左メニューの **Pages** を開く
3. 「Build and deployment」の **Branch** で、`claude/map-app-v0-1-az6aoa` ブランチと `/ (root)` を選び、**Save** を押す
4. 数分待ってから、表示されるURL（`https://gusk2020.github.io/world-viewer/` の形式）をPixel 7aのChromeで開く
