# 世界地図ビューア (world-viewer)

創作世界を表示するためのスマートフォン向けWeb地図アプリです。

現在のバージョン: **Three.js版 Version 0.6**

- 表示できる世界: 「過速世界」のみ（仮のデータ）
- できること:
  - 3Dの地球を指で回す・拡大縮小する（ピンチ操作）※確認済み
  - 2Dの世界地図（OpenLayers）※確認済み
  - 画面下のボタンで3D⇔2D表示を切り替え（見ていた場所・拡大の度合いを引き継ぎ）※確認済み
  - 森など暗かった場所を明るく見やすく調整 ※確認済み
  - **今回変更**: 3D地形の高さデータを、世界標準の海底地形データ **GEBCO_2026**
    に入れ替えました。陸地だけでなく**海底の地形**も、**北極・南極**も、
    ひとつの本物のデータで表示します
  - **今回変更**: 地球の画像（Blue Marble）は「地表の見た目」専用になり、
    3Dの高さには使わなくなりました
  - **今回変更**: 極点のまわりに出ていた放射状の筋を、データをぼかすのではなく
    **球体の作り方そのもの**を変えて解消しました（緯度経度の格子をやめ、
    どこでも同じ大きさのマス目になる方式に変更）
  - **今回変更**: 海面上昇スライダーが**実際のメートル単位**になりました
    （+0m〜+100m。100mは地球上の氷がすべて溶けた場合より少し多いくらいです）
  - **今回変更**: **「海の濃さ」スライダー**を追加しました。薄くすると海底の地形が
    見えやすくなり、濃くすると水没の様子が分かりやすくなります
  - **今回修正**: 浅い海に出ていた**黒い丸いムラ**を直しました（海面の丸みが粗く、
    海底が海面を突き抜けて見えていたのが原因です）
  - **今回変更**: 地表の画像を**2倍の細かさ**（4096×2048）にしました。雲のない画像
    なので、地面そのものが見やすくなっています
  - **今回修正**: 光を視点に合わせて動かすようにしました。以前は光が大西洋の真上に
    固定されていたため、その裏側の太平洋が暗く平坦に見えていました。どの海を見ても
    海底の起伏が見えます
- 対応端末: Android の Google Chrome（Pixel 7a で確認済み）
- 注意:
  - 地表の画像・地形データ・2D地図は、過速世界の実際の地形ではなく、実際の地球のもの（仮）です。過速世界の本当の地図ができ次第、差し替えます。
  - 地形の高さは、実際の縮尺のままだと地球はほぼ真ん丸に見えてしまうため（これは現実の地球でも同じです）、見やすいように誇張して表示しています。データ自体は本物です。
  - 誇張は地形と海面の**両方に同じだけ**かけているので、「どこが水没するか」は誇張しても正確なままです。
  - 2D地図は普通のWeb地図と同じ理由で、北極点・南極点そのものは地図の端で切れます（3Dとは別の、ふつうの地図の仕組み上の制限で、問題ではありません）。
  - 3D→2D→3Dと切り替えたとき、拡大の度合い（ズーム）は「だいたい」しか引き継げません。
  - 南極・北極の超高解像度データ（REMA / ArcticDEM）は、今後の追加予定です。
  - 今後、都市・国境などの過速世界データ（V0.7以降）の順に、1段階ずつ進めていきます。
  - 古いMapLibre／CesiumJS版は削除せず、`legacy-cesium-maplibre-v0` というブランチに保存してあります。いつでも元に戻せます。

## 地形データについて（自動処理）

元のGEBCO_2026は約7.5GBあり、スマートフォンでは扱えません。
そこでGitHubのサーバー側（GitHub Actions）で自動的に、

1. GEBCO公式（CEDA）から元データを取得
2. 平均化して縮小（点を間引くと山や海溝が消えてしまうため）
3. アプリで読める軽いPNG（数百KB〜数MB）を生成
4. 軽いPNGだけをこのリポジトリに保存（元の巨大ファイルは保存しません）

という処理を行っています。手作業でのダウンロードや変換は不要です。
更新したいときは GitHub の **Actions** タブから
「Build terrain from GEBCO」を実行するだけです（30分ほどかかります）。

## スマートフォンで見る方法

GitHub Pages（無料のホームページ公開機能）を使います。設定は最初の1回だけです。

1. このリポジトリの **Settings**（設定）を開く
2. 左メニューの **Pages** を開く
3. 「Build and deployment」の **Branch** で、`claude/map-app-v0-1-az6aoa` ブランチと `/ (root)` を選び、**Save** を押す
4. 数分待ってから、表示されるURL（`https://gusk2020.github.io/world-viewer/` の形式）をPixel 7aのChromeで開く
   - 画面下の「2Dに切替」「3Dに切替」ボタンで表示を切り替えられます
