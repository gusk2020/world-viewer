# 世界地図ビューア (world-viewer)

創作世界を表示するためのスマートフォン向けWeb地図アプリです。

現在のバージョン: **Three.js版 Version 0.7.1**

- 表示できる天体: **地球 / 火星 / 月**（画面上の「天体」ボタンで切り替え）

  - 3Dの地球を指で回す・拡大縮小する（ピンチ操作）※確認済み
  - 2Dの世界地図（OpenLayers）※確認済み
  - 画面下のボタンで3D⇔2D表示を切り替え（見ていた場所・拡大の度合いを引き継ぎ）※確認済み
  - 森など暗かった場所を明るく見やすく調整 ※確認済み
  - **今回変更**: 3D地形の高さデータを、世界標準の海底地形データ **GEBCO_2026**
    に入れ替えました。陸地だけでなく**海底の地形**も、**北極・南極**も、
    ひとつの本物のデータで表示します
  - **今回変更**: 地球の画像（Blue Marble）は「地表の見た目」専用になり、

  - **今回変更**: 極点のまわりに出ていた放射状の筋を、データをぼかすのではなく

- 対応端末: Android の Google Chrome（Pixel 7a で確認済み）
- 注意:
  - 地表の画像・地形データ・2D地図は、過速世界の実際の地形ではなく、実際の地球のもの（仮）です。過速世界の本当の地図ができ次第、差し替えます。
  - 地形の高さは、実際の縮尺のままだと地球はほぼ真ん丸に見えてしまうため（これは現実の地球でも同じです）、見やすいように誇張して表示しています。データ自体は本物です。
  - 誇張は地形と海面の**両方に同じだけ**かけているので、「どこが水没するか」は誇張しても正確なままです。
  - 海底の**形**は本物のGEBCOデータですが、**色**は深さから作った人工的なものです(海底の写真は存在しないため)。
  - 「海底の色」を切り替えると、画像を塗り直すため一瞬(1秒弱)止まります。
  - 海面を下げたとき海岸の水際に青が残っていた件は修正済みです(地図データの精度ではなく、こちらの設定が原因でした)。より細かい地形データ(4096×2048)で試しても点々は4%しか減らなかったので、データを増やしても直らない種類のずれでした。
  - 湖(五大湖・バルト海周辺の湖など)は海ではないので、水を抜いても青いまま残ります。
  - 「海底の色」の切り替えは2回目以降が速くなりました(約0.2秒→約0.06秒)。
  - **今回の点検**: 見た目と機能はそのままに、プログラムの中身だけを整理しました
    (下記)。
  - 2D地図は普通のWeb地図と同じ理由で、北極点・南極点そのものは地図の端で切れます（3Dとは別の、ふつうの地図の仕組み上の制限で、問題ではありません）。
  - 3D→2D→3Dと切り替えたとき、拡大の度合い（ズーム）は「だいたい」しか引き継げません。
  - 南極・北極の超高解像度データ（REMA / ArcticDEM）は、今後の追加予定です。
  - 今後、都市・国境などの過速世界データ（V0.7以降）の順に、1段階ずつ進めていきます。
  - 古いMapLibre／CesiumJS版は削除せず、`legacy-cesium-maplibre-v0` というブランチに保存してあります。いつでも元に戻せます。

## 自転軸と経緯線（今回の追加）

3天体すべてで使えます。

- **自転軸ボタン（姿勢リセット）**: どんな向きに動かしていても、1回押すと
  **「ゼロ点の姿」**に戻ります＝赤道が水平、自転軸が垂直、そして
  **緯度0度・経度0度が画面の真ん中で正面**を向いた状態です。
  そこからもう1回押すと、その姿勢のまま**実際の自転軸の傾き**になります
  （地球 23.44°／火星 25.19°／月 6.68°。それぞれ自分の公転面に対する角度です）。
  拡大の度合いはそのままです（向きだけを戻します）。
  ボタンの横の数字は、**今画面上で軸が何度傾いて見えているか**です。
  指で動かすとリアルタイムに変わります。
- **経緯線ボタン**: 押すたびに
  **緯度線 → 緯度経度線 → 経度線 → なし** と切り替わります。
  線は地形に沿って引かれるので、山の上でも浮いたり埋まったりしません。
  拡大すると自動的に細かい間隔（30°→10°）に変わります。
- **縮尺**: 経緯線を1つでも表示している間だけ、画面左下に出ます。
  実際の映像で測って誤差0.0%であることを確認済みです。
  同じ拡大率でも天体ごとに違う値が出ます（地球1000km／火星500km／月200km）。

線の色は黒にしています。白い線だと砂漠のような明るい地面の上でほとんど
見えなくなるためで、実測して決めました（明るい地面での見やすさが約7倍）。

**今回修正**: 海の濃さを上げると経緯線が消えてしまう問題を直しました。
線が水の下に隠れていたのが原因で、線を水より手前に描くようにしました。
海の濃さ100%でも線がすべて見えます（火星で実測：以前は100%で線の約7割が
消えていました）。

**今回変更**: 操作パネルを小さくしました（画面の28%→19%）。
自転軸と経緯線のボタンを1行にまとめています。

## 火星と月について（今回の追加）

画面上の「**天体**」ボタンで、地球・火星・月を切り替えられます。
起動時は今までどおり地球です。

**使ったデータ（どちらもNASA/USGSの公式全球データ）**

- 火星: **MOLA 全球地形データ**（Mars MGS MOLA DEM global mosaic、463m/画素、約2.1GB）
  出典: USGS Astrogeology `planetarymaps.usgs.gov`
  高さの基準（0m）は火星の標準基準面「エアロイド」です。
- 月: **LOLA 全球地形データ**（LRO LOLA Global LDEM 118m、約8.5GB）
  出典: USGS Astrogeology `planetarymaps.usgs.gov`
  高さの基準（0m）は半径1737.4kmの球です。

巨大な元データはGitHubのサーバー側で処理し、**アプリに入るのは1天体あたり
約3MBの軽いデータだけ**です。スマホが巨大ファイルを読むことはありません。

**火星・月でできること**

- 実際の全球地形を3Dで見る（指で回す・拡大）
- 高さによる地球風の色分け（深い海＝濃い青 → 浅い海＝明るい青 →
  海岸＝黄緑 → 低地＝緑 → 高地＝黄〜茶 → 高山＝灰〜白）
- **仮想海面**を上下させて、「ここまで水があったらどこが海になるか」を見る
  - 火星: -9000m 〜 +6000m（100mきざみ）
  - 月: -9000m 〜 +5000m（100mきざみ）
- 水の濃さの調節

**注意**

- 火星と月に海はありません。海面スライダーは「もし水があったら」を
  見るための**仮想**のものです。画面にもそう表示しています。
- 地形の**形**は本物のデータですが、**色**は高さから作った人工的なものです。
- 色分けの設定は天体ごとの設定ファイルで変えられます。
- 火星・月には衛星写真をまだ使っていません（今回は地形優先です）。
- 2D地図は地球の地図なので、火星・月では表示されません。

## 地形データについて（自動処理）

元のGEBCO_2026は約7.5GBあり、スマートフォンでは扱えません。
そこでGitHubのサーバー側（GitHub Actions）で自動的に、

1. GEBCO公式（CEDA）から元データを取得
2. 平均化して縮小（点を間引くと山や海溝が消えてしまうため）
3. アプリで読める軽いPNG（数百KB〜数MB）を生成
4. 軽いPNGだけをこのリポジトリに保存（元の巨大ファイルは保存しません）

という処理を行っています。手作業でのダウンロードや変換は不要です。
更新したいときは GitHub の **Actions** タブから
「Build terrain」を実行し、天体（kasoku-sekai=地球 / mars / moon）を
選ぶだけです。

## スマートフォンで見る方法

GitHub Pages（無料のホームページ公開機能）を使います。設定は最初の1回だけです。

1. このリポジトリの **Settings**（設定）を開く
2. 左メニューの **Pages** を開く
3. 「Build and deployment」の **Branch** で、`claude/map-app-v0-1-az6aoa` ブランチと `/ (root)` を選び、**Save** を押す
4. 数分待ってから、表示されるURL（`https://gusk2020.github.io/world-viewer/` の形式）をPixel 7aのChromeで開く
   - 画面下の「2Dに切替」「3Dに切替」ボタンで表示を切り替えられます
