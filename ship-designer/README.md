# 過速世界｜恒星間船 居住シリンダー設計台帳 v10

スマホ（Pixel 7a 縦持ち）優先の静的Webアプリ。`index.html` をそのまま開けば動く（ビルド不要）。
v9 設計台帳の後継。world-viewer（地図アプリ）本体とは独立したフォルダで、world-viewer のコードは読み込まない。

- 2D展開図：船体枠の移動・辺/角つまみ変形、日本列島モード、縮尺・南方離島間隔・対馬・小笠原圧縮の±（長押し連続）、比較案、保存・JSON入出力
- 3D：全体透過・断面・船内地表。2Dと同じ地図をシリンダー内面に貼る
- 詳細記録：`docs/DEVLOG.md`（技術判断・試験・引継ぎ）、`docs/DATA.md`（出典・精度）

テスト：`npm test`（計算） / `THREE_DIR=<three@0.128.0 を展開したフォルダ> npm run test:e2e`（Pixel 7 相当の操作）
