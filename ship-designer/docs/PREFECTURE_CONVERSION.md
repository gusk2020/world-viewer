# 旧49府県 → 船内47都道府県 の変換規則（v11）

元データ：gusk2020/kudo-fudo-miseisen `src/data/japan.json`（commit 69221ca）の 49 府県。**元の49件は `data/ship-geo.json` の `legacyPrefectures` にそのまま保持**（削除・改変なし）。船内で使うのは `prefectures`（47件）。

| 規則 | 内容 |
|---|---|
| 北海道の再統合 | 札幌県(HK-SAP)・函館県(HK-HAK)・根室県(HK-NEM) → `JP-01 北海道` 1件。県庁は札幌市。重みは3県の合計(480)。`mergedFrom` に元3県を記録 |
| 内部境界 | 北海道の内部の県境は生成しない（境界線 0 本）。海岸線・標高・都市は変更しない |
| 都市 | 函館市・根室市は県庁ではなく通常の都市として残す（`legacyCapitalOf` に元の県を記録）。札幌市は北海道の県庁 |
| 東京 | `JP-13` の名称を「東京府」→「東京都」。IDは同じ。旧名は `legacyName` に記録 |
| 他の45府県 | 酷道と同じ重み・同じ平均重み（49件基準）で境界を再生成。v10 と同一の境界 |
| 島の所属 | 伊豆・小笠原・鳥島群 → JP-13。北方領土4島・歯舞群島 → JP-01。竹島 → JP-32。**日本側の行政区分データに沿った紐付けであり、実世界の国際的立場を設定上の結論として確定するものではない** |
| 表示 | 地図上には県名を出さない（メニューの県名切替は削除）。県名・県ID・県境・面積・県庁は内部データとして保持し、メニューの表には出る。世界文化の割当や人口計算は `prefectures[].culture`（null の受け皿）から後で行う |

境界は酷道の「重み付き Dijkstra」（傾斜コスト）による生成物で、実在の県境ではない。面積は 2.5km 格子の集計値（参考値）。
