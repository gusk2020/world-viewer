## 2. 座標の流れ（段階を分離）
地理(経度,緯度) → v9平面km → 島補正（南方離島間隔: 31°N へ寄せる／対馬南下／小笠原圧縮: 硫黄島固定で北側のみ／個別東西補正）→ ÷縮尺分母で船体km（x東, y北＝船首）→ 2D: x を円周で折り返し → 3D: θ=(x−西端)/円周·2π, 位置(−r·sinθ, −r·cosθ, y−中心)。
- 3Dは内側から船首を向いて立つと東が右（地図が鏡像にならない）。
- 島補正は島単位の剛体移動。府県境・県名・都市は所属島の補正をそのまま受ける（テストで確認）。
- 原島座標は一切書き換えない。個別補正は `terrain.islandOffsetsKm`（船体km、+東）に独立保存。

## 3. 干渉判定
- 物理干渉＝実際の陸地ポリゴン同士の重なり面積。周回コピー（k·円周ずらし）も対象、円周より長い島の自己重なりも対象。
- 行ごとの区間交差（160行）で面積と赤い面を作る。接するだけは0。表示用の小島記号（点）は判定に使わない。
- 南西諸島の自動解消 `resolveRyukyu`：南西諸島を含む重なりについて小さい方の島を東西のどちらか近い側へ最小移動（二分探索＋4m余裕）、新たな重なりを作らない位置のみ採用。

- **船内標高 = 実標高 × 10 / 縮尺分母 × 全体倍率**（1/40なら実物の1/4、富士山3776m→基準944m）。`ShipTerrain.VERTICAL_FACTOR = 10`。独立した高さ縮尺(1/5〜1/10)は引き続き無い。
