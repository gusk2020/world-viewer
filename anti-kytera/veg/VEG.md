# Anti-KyTerra 植生レイヤー（試作、2026-09-27）

PR #12（地形→海→気温→湿度→降水→陸氷）の受け渡しデータ `handoff/interface_v3.npz` だけを入力にして、**通年の代表的な自然植生**を1枚の地図にする。PR #12 のコードは変更していない。季節の切り替えはない。

## 入力と格子の合わせ方
| 入力 | 格子 | 使い方 |
| --- | --- | --- |
| `bed_m` / 陸海（岩盤 ≥ 0 m） | 0.25° | 0.5° へは面積平均（陸の割合・平均標高・起伏・300〜3000 km 平滑・風上/風下の海と山）。表示では 0.25° のまま海岸線と陰影に使う |
| `ice_mask_{fit,holdout}` | 0.5° | 表示で最優先（海面下の岩盤上の接地氷も含む） |
| `t2m_c` / `precip_mm_yr` / `vapour_pressure_hpa`（`_fit` または `_holdout`） | 2° | セル中心どうしで 0.5° セル中心へ双線形補間（経度は周回）。気温は 0.5° の平均標高へ一定の減率 6.5 K/km で移す |

- 気候から作る特徴：気温、log 降水、log 水蒸気圧、相対湿度、飽差、生物温度（0〜30 °C に制限）、降水/可能蒸発散の比（Holdridge 1967：可能蒸発散 = 58.93 × 生物温度 mm/年）。
- 地形の特徴は PR #12 と同じ（`stat/features.py`）。緯度は、地軸の傾きから計算した日射（年平均と季節幅）としてだけ入る。**地名・経度・座標は使っていない。**
- **教師の気温・降水・湿度・氷は、予測の入力には使っていない。** 地球適合は `_fit` 気候、地域保留は `_holdout` 気候を使う。

## 教師
| データ | 内容 | 利用条件（実際の記載） |
| --- | --- | --- |
| Ramankutty & Foley (1999) Global Potential Vegetation, 0.5°（SAGE, University of Wisconsin） | 人の土地利用が無かった場合の植生、15 区分。DISCover 1 km 土地被覆から作り、農地などの所は Haxeltine & Prentice の値で埋めている。ツンドラ・極地荒原の判定と熱帯/温帯/北方の分けには気候の規則が使われている | 同じデータの NASA/ORNL DAAC 版（ISLSCP II）は「EOSDIS のデータ利用・引用指針に従い、制限なく公開」。SAGE のページはこの作業環境から開けず、原文は未確認。引用：Ramankutty, N. & Foley, J.A. (1999) Global Biogeochemical Cycles 13(4), 997–1027 |

- 取得：`python3 veg/fetch_teacher.py`（`sage-public-files.s3.amazonaws.com/global-potential-vegetation/potveg_nc.tar.gz` から `vegtype_0.5.nc` を取り出す）。保存先は `veg/data/pnv_rf_0.5deg.png`。8 bit の画像で、1 行目が北、値 0 は区分なし。
- 学習・評価の対象：教師に区分があり、かつ岩盤で陸（0.5° セルの陸の割合 ≥ 0.5）のセル。**南極は教師に区分が無い**ため、学習にも評価にも入らない（表示ではほぼ氷の下）。

## 分類値と表示の順序（将来のレイヤー用）
| 値 | 意味 |
| --- | --- |
| 0 | 海（岩盤 < 0 m） |
| 1 | 陸氷（接地氷。海面下の岩盤上にもある） |
| 11–25 | 植生 = R&F の区分 + 10（11 熱帯常緑林, 12 熱帯落葉林, 13 温帯常緑広葉樹林, 14 温帯常緑針葉樹林, 15 温帯落葉樹林, 16 北方常緑林, 17 北方落葉林, 18 混交林, 19 サバンナ, 20 草原・ステップ, 21 密な低木地, 22 疎な低木地, 23 ツンドラ, 24 砂漠, 25 極地荒原・岩） |
| 30 | 予約：川・湖 |
| 40 / 41 | 予約：農地 / 灌漑地 |
| 50 | 予約：街 |
| 255 | 教師に区分なし（教師の表示だけ） |

**重ねる順（下→上）：海 → 植生 → 農地・灌漑地 → 川・湖 → 街 → 陸氷。** 上の層がある所では下の層は隠れる。植生は、将来の層の下に敷く「人の手が入る前の状態」として扱う。予約した値（30/40/41/50）は今回は作っていない。

## 手法
- 分類器：HistGradientBoosting（scikit-learn）。15 区分を学習し、セルの面積で重み付けしている。
- 地球適合：地球全体で学習し、地球全体に当てはめる。
- 地域保留：経度 60° ごとの 6 帯について、その帯を学習から外したモデルで予測する。気候の入力も、PR #12 の地域保留の値を使う。
- 作り直し：`python3 veg/fit_veg.py && python3 veg/export_veg.py`（約 3 分）。

## 教師との比較（陸の教師セル、面積重み）
| | 地球適合 | 地域保留 |
| --- | --- | --- |
| 15 区分の一致率 | 97.4% | **33.4%** |
| κ | 0.97 | **0.25** |
| 大区分（森林／サバンナ・草原／低木・砂漠／ツンドラ・極地）の一致率 | 98.5% | **54.6%** |
| 帯ごとの一致率（経度 −180 から 60° ずつ） | 0.96–0.98 | 0.32 / 0.38 / 0.38 / 0.26 / 0.36 / 0.36 |

- 地球適合の値は、学習した場所への当てはめなのでほぼ一致して当然。多くの地形特徴が場所の目印として働き、覚えてしまっている。実力の目安は地域保留の列。
- 地域保留で種類ごとの一致度（IoU）が高いのは、熱帯常緑林 0.39、草原 0.34、北方落葉林 0.30、混交林 0.26。低いのは、温帯常緑広葉樹林 0.00、熱帯落葉林 0.02、温帯常緑針葉樹林 0.04 で、ほぼ出ていない。
- 特徴の組み合わせの比較（地域保留）：気候だけ 27.0%、＋日射・標高 29.0%、＋大陸度 31.2%、全部 33.4%。スマホ版は全部を使っている。確率の空間平滑は +0.3 点で効果がほぼ無いので、使っていない。
- 原因を分けるための診断（出力や表示には使っていない）：同じ地域保留の分類に**教師の気候**を入れた場合でも 48.7%（大区分 68.5%）。つまり、15 区分を未知の地域で当てる分類そのものの限界が約 49%。そこから PR #12 の地域保留の気候の誤差で、さらに約 15 点下がっている。

## 限界
1. **季節性を区別できない。** 入力は年平均の気温・降水・水蒸気圧だけなので、常緑か落葉か、熱帯季節林・サバンナか熱帯多雨林か、雨季があるかといった違いは、直接には判定できない。日射の季節幅と大陸度（地形の特徴）が間接的な手がかりになるだけ。上の誤分類の半分以上がこれにあたる。
2. 教師（R&F）の熱帯・温帯・北方の境界や、ツンドラ・極地荒原の判定は、もともと気候の規則で作られている。地球適合の一致には、その規則を覚え直した分も含まれる。
3. 教師には、北米の一部で熱帯落葉林を温帯落葉樹林に手で直した所がある（README の記載）。
4. 南極は教師に区分が無く、評価の対象外。
5. 経度帯の境目に、気候の入力（PR #12 の地域保留）から来る段差が残る。
