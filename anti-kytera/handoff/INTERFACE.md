# Anti-KyTerra 接続仕様 v3（植生など他の試作向け）

ファイル：`anti-kytera/handoff/interface_v3.npz`（numpy の `np.load` で読む。作り直しは `python3 stat/export_handoff.py`）
内容は段階版 v3（`STAGES.md`）の最終結果。植生の実装はこのPRには含まない。

## 共通の約束
- **格子**：規則的な緯度経度。**行0が最南端**、列0が経度 −180 から始まる。値はセル中心の値（セル面積の平均）。
- **欠損値：なし。** 全セル（陸も海も）に値がある。NaN もフィル値も使っていない。
- **期間**：すべて年平均の気候値（季節・月別はない）。モデルは 1991–2020 の教師に合わせて学習した静的な推定値で、特定の年の値ではない。湿度の教師だけは 1994/2001/2008/2015 年の抽出。
- **2つの版**：`_fit`＝地球適合（学習した地球への当てはめ）、`_holdout`＝地域保留（経度60°帯ごとに、その帯を学習から外して予測）。`_teacher`＝比較用の教師値。

## 項目
| キー | 格子 | 型・単位 | 定義 |
| --- | --- | --- | --- |
| `bed_m` | 0.25°（720×1440） | int16, m | 岩盤標高。GEBCO_2026 sub-ice 版、補正 0 m |
| `land_mask` | 0.25°（720×1440） | uint8, 1=陸 0=海 | **陸海マスク**：岩盤 ≥ 0 m が陸（海抜 0 m 固定） |
| `ice_mask_fit` / `_holdout` | 0.5°（360×720） | uint8, 1=氷床 | **氷床マスク**：推定氷厚 > 10 m。**海面下の岩盤の上にもある**（西南極など。陸海マスクでは海のセル） |
| `ice_thickness_m_fit` / `_holdout` / `_teacher` | 0.5°（360×720） | float32, m | 接地氷の厚さ。教師は GEBCO 氷表面 − 岩盤 |
| `t2m_c_fit` / `_holdout` / `_teacher` | 2°（90×180） | float32, °C | 年平均の地表 2 m 気温。教師は実際の地表（氷床表面を含む）の値 |
| `precip_mm_yr_fit` / `_holdout` / `_teacher` | 2°（90×180） | float32, mm/年 | 年降水量 |
| `vapour_pressure_hpa_fit` / `_holdout` / `_teacher` | 2°（90×180） | float32, hPa | 年平均の地表付近水蒸気圧（2 m 露点から） |

## 注意
- 格子の大きさが項目ごとに違う（0.25° / 0.5° / 2°）。細かい格子に合わせるときは、2° の1セルを 0.5° では 4×4、0.25° では 8×8 に複製すれば位置がずれない。
- 気温は教師の地表高度に合わせた値ではなく、岩盤地形などから推定した値。氷床の上では、実際の氷表面の高さによる冷え込みは推定の中に含まれている（教師がそうなっているため）。
- 陸海マスクは岩盤で決めているため、現在の地表では陸だが、ここでは海になる所が地表面積の約 1.4% ある（主に氷床の下で海面下にある岩盤）。
