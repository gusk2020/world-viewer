# Anti-KyTerra v2（基準版）

PR #15 の統合試作（v1s の見た目 + PR #14 の7段階）を、Pixel 7a で確認した見た目のまま整理した版。**基準条件（海面0 m・14℃）での推定・教師・分類・数値・配色・境界は PR #15 と同じ**（その後、スライダー追従と積雪・海氷の重ね描きが加わった。下記）。既存アプリ・v1s・PR #12〜#15 のファイルは変更していない。

## v2 で使う入口・データ・表示条件
- **入口**：`anti-kytera/viewer/index.html`（画面右上に「Anti-KyTerra v2」）。
- **データ**（`AK_BASE` = `anti-kytera/` からの相対）：
  - `results/display.json` ・ `results/fields.bin` … 1〜6段階（岩盤・海・気温・湿度・降水・陸氷）のモデルと教師、地球適合／地域保留（PR #12 / #14）
  - `veg/results/veg_display.json` ・ `veg/results/veg_fields.bin` … 7段階目の植生（PR #13）
  - `worlds/*/` … 標準の衛星写真・GEBCO 氷表面の標高・火星と月（v1s からのコピー）
- **表示条件**：採用済みの推定はすべて**現在条件（平均気温14℃・海面0 m）**。7段階は5天体すべてにある（地球以外は教師なし）。

## 海面・平均気温を動かした時
- 7段階（岩盤〜植生）は両方のスライダーに**追従する**。海陸→気温→湿度→降水→陸氷→植生を、全天体共通の簡易規則で更新する（方法・仮定・計算時間は `RESPONSE.md`）。干上がった海底も塗る。
- 海面0 m・14℃では採用済みの「地球適合」の結果をそのまま表示する。それ以外では教師が無く、中央の欄は「モデル値／教師なし」。教師・差は地球の基準条件だけ。
- 標準画像・標高色は画像と地形が変わらず、海面だけが動く。
- 天体を切り替えると海面は0 mに戻り、平均気温はそのまま引き継ぐ。
- 陸氷（氷床・氷河）とは別に、季節の積雪（陸の上）と海氷（海の上）を、1年のうち覆われる割合で重ねて描く（植生・陸氷の段、3D/2D共通）。寒冷化の陸氷は最暖月の温度で決める。方法・ERA5（再解析）での確認・変化の規模は `RESPONSE.md`。

## 役割（`js/`）
| ファイル | 役割 |
| --- | --- |
| `main.js` | 入口。天体の読み込みと安全な切替、パネル操作、3D/2D切替（向き・拡大率の引き継ぎ）、中央の値の表示 |
| `stages.js` | 7段階の組み立て。状態（段・モデル/教師/差・植生表示・海面・平均気温・海の濃さ）を1つ持ち、下の4つに渡す |
| `stage-data.js` | **読み込み**と判定：元データ（F）、極域の東西平均をかけた描画用コピー（D）、氷＞海＞植生の判定。地域保留の配列はファイルに残るが使わない |
| `stage-draw.js` | **表示**：配色と、3D（Lambert 材質の地色）と2D（メルカトル）が**共用する同じ色の式**（GLSL 1本） |
| `stage-respond.js` | 海面・平均気温に応じて7段階の値と積雪・海氷を更新（`rules/response_rules.json` の共通規則を使う。方法は `RESPONSE.md`） |
| `stage-panel.js` | 凡例・注意書きと**中央の元データ値**（元データ F を読む。描画用コピーと違う時はそう書く） |
| `globe3d.js` | 3D表示（v1s）。光・操作・海・軸・線。7段階用は岩盤形状のメッシュ |
| `map2d.js` | 2D表示（v1s の OpenLayers）。3D と同じ色の式でメルカトル上に描く |
| `graticule.js` `cubeSphere.js` `elevation.js` `geoConvert.js` `hypsometric.js` `surface.js` | v1s の部品（使う部分だけ） |

3D と 2D は同じ `stages.js` の状態・配色・判定・描画用コピーを読むので、同じ段・同じ地点は同じ色になる。

## v1s から外したもの
Climate v1・旧気候塗り分け・教師比較・季節・海氷・惑星設定・公転の UI とコード（今の積雪・海氷の重ね描きは `stage-respond.js` の別の簡易規則）、海底の色の切替（「写真」に固定）、未使用の設定項目（海底色の深さ、地形生成・検証の設定）。

## 整理で直した不具合
- 2D の「標準」で、水域の色付けが南北逆だった（標高の格子は北が先頭なのに南が先頭として読んでいた）。3D と同じ向きに直した。
- 2D 表示中も、見えない3D地球儀を毎フレーム描き続けていた。表示されない描画がGPUに溜まり、2Dの再描画（海面・海の濃さの操作）を待たせる原因になるので、2D 中は3Dを描かないようにした（見た目は同じ）。

## 天体の追加分（PR #17・#18）と修正
- 月・火星・水星・金星にも、地球で学習した規則による7段階の試験表示がある（教師なし）。出典・処理は `worlds/PLANETARY_V2.md` と `worlds/EXPANDED_VIEW.md`。
- 地形・画像・7段階・中央の値が同じ場所を指すことは `tools/verify_planet_alignment.py` で確かめる（ラフマニノフ盆地、マクスウェル山、マート山、オリンポス山、ヘラス最深部、月の最高点）。
- 地球適合を採用済み：地球適合／地域保留の切替はない。教師・差は地球だけで、天体を切り替えるとモデルに戻る。
- 天体の読み込みに失敗したときは、元の天体に戻るボタンを出す（6秒で自動的にも閉じる）。
- 標高色・岩盤・海の色の両端は天体ごと（`display.reliefColourRangeMetres`、地球は −8000〜6000 m のまま）。

## 形について
- 7段階の形は Anti-KyTerra の岩盤（GEBCO_2026 氷床下地形、0.25°）を v1s と同じ30倍で強調。氷床の厚みは形に入らない。
- 標準の形は v1s と同じ GEBCO_2026 の氷表面。
