## 画面
- 地表の段：標準（v1s の衛星写真）・岩盤・海・気温・湿度・降水・陸氷・植生。7段階は地球だけ。火星と月は v1s の従来表示。
- 表示（モデル／教師／差）と検証（地球適合／地域保留）は、気温〜植生で使える。
- 海底の色は v1s の既定の「写真」に固定した。「寒冷・現在・温暖」の切替はない。
- 海面の高さ・平均気温：推定は現在条件（平均気温14℃・海面0 m）のまま。どちらかを動かすと、パネルに「追従しない」と出る。塗り分けと動いた海面が食い違う所では、海面を優先する（海面より下は海、下げて干上がった海底は「推定なし」）。中央の欄にも出す。平均気温は、表示を何も変えない。
- 中央の値：3Dでも2Dでも、画面中央の地点の元データ値（モデルと教師）。
- 軸：v1s と同じ。線：なし→緯度→緯度経度→経度。線色：黒／白。

## 形について
- 7段階の地球儀の形は、Anti-KyTerra の岩盤（GEBCO_2026 氷床下地形、0.25°）を v1s と同じ30倍で強調したもの。氷床の厚みは形に入らない。
- 標準（衛星写真）の形は、v1s と同じ GEBCO_2026 の氷表面。
