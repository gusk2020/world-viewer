# 海面・平均気温への追従（試作）

海面と平均気温のスライダーを動かすと、7段階（岩盤〜植生）の塗り分けが3D・2Dとも実際に変わる。陸氷とは別に、積雪（陸の上）と海氷（海の上）も重ねて描く。細かな物理より「操作に一貫して反応すること」を優先した簡易規則で、全天体に同じ規則を使う（地名・天体名による補正はない）。

## 方法（`js/stage-respond.js`）
各天体の基準（海面0 m・14℃）の採用済み推定を出発点に、差分だけを足す。定数は `rules/response_rules.json`（`tools/build_response_rules.py` が作る）にある。

| 段 | 規則 |
| --- | --- |
| 海陸 | 岩盤 ≥ 指定海面なら陸（画素ごと） |
| 気温 | 基準 + ΔT ×（1 + 0.8(sin²緯度 − 1/3)）。極域で大きく、全球平均はΔTのまま |
| 湿度 | 基準 × exp(0.064 ΔT)（相対湿度一定）× 海岸係数 |
| 降水 | 基準 × exp(0.02 ΔT) × 海岸係数 |
| 海岸係数 | exp(−(新しい海までの距離 − 基準の距離) / 1000 km)、0.25〜2.5に制限（2°格子） |
| 陸氷 | 最暖月の気温で決める（下記）。海面上昇で浮く（水深 > 厚さの0.9）氷は消える |
| 積雪 | 陸氷のない陸で、1年のうち気温が −2℃ 未満の割合 ×（降水/200 mm、最大1） |
| 海氷 | 海の上で、1年のうち気温が −5℃ 未満の割合 |
| 植生 | 表「気温×降水ごとの各植生の割合」。新しい気候での割合が基準の半分未満（差0.05以上）になった時だけ、その気候で最も多い植生に替える |
| 干上がった海底 | 基準値が無いので、規則の答えをそのまま使う（「推定なし」にしない） |

- 年較差（最暖月 − 最寒月）：夏至と冬至の日射の差（自転軸傾斜と緯度から計算）× 0.085。陸は海から遠いほど大きく（海岸で45%、500 kmで増える）、海は × 0.0175。ERA5（2015年の1月と7月）に合わせた。誤差は陸6.2 K・海3.6 K。
- 陸氷：最暖月（年平均 + 年較差/2）が「氷河が夏を越せる温度」（降水500 mm/年で4℃、倍になるごとに+1.5℃、150 mm未満では不可）を下回り、しかもその地点の基準の最暖月より3℃以上低い時にできる。厚さは300 m＋冷えた度数×200 m（最大3000 m）。採用済みの陸氷は逆の条件で融ける。
- 積雪と海氷は、この割合で濃さを変えて重ねる（積雪は植生の上、海氷は海の上）。季節の切替は作らず、通年の代表的な姿として描く。植生の分類そのものは変えない。
- 植生の表は地球の「地球適合」結果から作る（3×3で平滑化）。月・火星・水星・金星も同じ表を使う。

## 仮定
- 海面は気温を変えない。氷の厚さは冷えた度数から決める簡易式。
- 植生の表は地球の気候だけから作るので、地球に無い気候では最も近い表の値を使う。高さ（高原か低地か）は区別しない。

## 基準条件
- 海面0 m・14℃では、気温・湿度・降水・陸氷・植生は採用済みの配列をそのまま戻す（積雪と海氷だけは採用済みの値が無いので、この規則で計算する）。
- 教師・差・一致率は地球の基準条件だけ。それ以外と他天体では、中央の欄は「モデル値／教師なし」。

## 以前の陸氷規則と、寒冷化で氷が広がらなかった原因
PR #20 では、地球の結果から作った「気温×降水ごとの氷の割合」表を使い、割合が0.5を超え、しかも基準より0.2以上増えた時だけ氷を作っていた。現在の地球で陸氷があるのは南極・グリーンランドの内陸だけなので、表で割合が0.5を超えるのは年平均およそ −15℃ 以下（降水200〜400 mm）に限られる。カナダ・北欧・シベリアは今 −5〜+4℃ で、平均気温を5℃まで下げても約 −14℃ にしかならず、氷ができなかった。そのため最暖月の規則に替えた（表は使わなくなったので、規則ファイルからも外した）。

## 現在の地球での確認（教師ではない）
雪・海氷の参考には ERA5（ECMWF の**再解析**。観測そのものではない）の2015年を使った。NSF NCAR の公開ミラー s3://nsf-ncar-era5（d633000）から、海氷割合（CI）・積雪深（SD、水換算 > 0.01 m を積雪ありとする）・2 m 気温を取得した（`tools/build_cryo_reference.py` → `rules/cryo_reference_2015.npz`）。用途は基準条件での見た目と定数の確認だけ。一致率は画面に出さず、基準以外の条件や他の天体では使わない。

| 地球全体に占める割合 | ERA5 2015 | モデル（基準） |
| --- | --- | --- |
| 積雪（1年のうち覆う割合 × 面積） | 3.95% | 4.17% |
| 海氷（同上、陸氷の上を除く） | 3.68% | 3.80% |

## 変化の規模（地球。面積は地球全体に占める割合）
| 条件 | 陸 | 陸氷 | 積雪 | 海氷 |
| --- | --- | --- | --- | --- |
| 14℃（基準） | 27.6% | 2.8% | 4.2% | 3.8% |
| 10℃ | | 4.7% | 4.0% | 7.4% |
| 5℃ | | 7.3% | 3.6% | 13.5% |
| 5℃・海面 −120 m | 31.8% | 7.2% | 4.5% | 12.3% |
| 20℃ | | 2.4% | 2.5% | 1.0% |
| 25℃ | | 1.8% | 1.4% | 0.3% |
| 14℃・海面 +200 m | 19.4% | | | |
| 14℃・海面 −6000 m | 99.8% | | | |

- 5℃では北欧・ハドソン湾の南・ケベックが氷に覆われ、海氷が中緯度の海まで広がる。25℃では高地の氷が減り、森林・サバンナが広がる。
- 海面 −6000 m では内陸は海から遠くなって乾燥し、砂漠・草原が広がる。−120 m では干上がった大陸棚にも植生が付く。+200 m では沿岸が沈み、残った陸の沿岸は湿る。
- 参考までに、最終氷期最盛期の陸氷は現在のおよそ2.5倍（地球全体の約8%）とされる。5℃ではそれに近い規模になるが、これは規模の目安にしただけで、任意のスライダー値の教師としては使っていない。
- 他の天体でも、両端で陸海・植生・氷が同じ向きに変わる。

## 計算時間
スライダーを止めてから0.15秒後（離した時は即時）に1回計算する。ソフト描画の試験環境で1回 90〜135 ms。スマホでは数倍かかる見込み。

## 限界・目立つ不自然さ
- 植生は気温と降水の表だけなので、冷えた高原が森林になるなど、地球の実際と違う変化が出ることがある。
- 5℃では、実際の最終氷期ではほぼ氷がなかったシベリア北部まで氷床になる。乾燥の効果は、降水150 mm未満の条件だけで弱い。
- 軸傾斜の小さい天体（月・水星・金星）は季節がほぼ無いので、積雪・海氷の縁が急になり、冷やすと陸氷が広く一気に広がる。
- 基準（14℃）ではハドソン湾・オホーツク海の海氷がERA5より少ない（海の年較差が小さめで、−5℃を下回る期間が短く出る）。
- 基準の積雪は灰色がかって見える。
- 海面0 m・14℃以外の値には教師が無く、正しさは確かめられない。
