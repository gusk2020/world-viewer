# 海面・平均気温への追従（試作）

海面と平均気温のスライダーを動かすと、7段階（岩盤〜植生）の塗り分けが3D・2Dとも実際に変わる。細かな物理より「操作に一貫して反応すること」を優先した簡易規則で、全天体に同じ規則を使う（地名・天体名による補正はない）。

## 方法（`js/stage-respond.js`）
各天体の基準（海面0 m・14℃）の採用済み推定を出発点に、差分だけを足す。

| 段 | 規則 |
| --- | --- |
| 海陸 | 岩盤 ≥ 指定海面なら陸（画素ごと、従来どおり） |
| 気温 | 基準 + (平均気温 − 14℃) |
| 湿度 | 基準 × exp(0.064 ΔT)（相対湿度一定）× 海岸係数 |
| 降水 | 基準 × exp(0.02 ΔT) × 海岸係数 |
| 海岸係数 | exp(−(新しい海までの距離 − 基準の距離) / 1000 km)、0.25〜2.5に制限（2°格子） |
| 陸氷 | 表「気温×降水ごとの氷の割合」。割合が0.5を下回り基準より0.2以上下がれば融ける、0.5を超え0.2以上上がれば生じる。海面上昇で浮く（水深 > 厚さの0.9）氷は消える |
| 植生 | 表「気温×降水ごとの各植生の割合」。新しい気候での割合が基準の半分未満（差0.05以上）になった時だけ、その気候で最も多い植生に替える |
| 干上がった海底 | 基準値が無いので、表の答えをそのまま使う（「推定なし」にしない） |

表は `rules/response_rules.json`（`tools/build_response_rules.py` が地球の「地球適合」結果から作る。3×3で平滑化）。月・火星・水星・金星も同じ表を使う。

## 仮定
- 気温変化は全球一様、海面は気温を変えない、氷の厚さは表の平均値、海氷は扱わない。
- 表は地球の気候だけから作るので、地球に無い気候では最も近い表の値を使う。
- 植生の表は気温と降水だけで、高さ（高原か低地か）は区別しない。

## 基準条件との一致
- 海面0 m・14℃では計算せず、採用済みの配列をそのまま戻す。PR #19 と比べ、地球の4視点×8表示と教師・差の画面は **差0画素**。
- 教師・差・一致率は地球の基準条件だけ。それ以外と他天体では、中央の欄は「モデル値／教師なし」。

## スライダー両端（地球）
- 海面 −6000 m：陸99.8%（基準27.6%）。内陸は海から遠くなり乾燥し、砂漠・草原が広がる。
- 海面 −120 m：陸31.8%。干上がった大陸棚にも植生が付く。内陸はほぼ変わらない。
- 海面 +200 m：陸19.4%。沿岸が沈み、残った陸の沿岸は湿る。
- 平均気温 5℃：チベット等に氷が広がり、ツンドラが南へ広がる。
- 平均気温 25℃：高地の氷が減り、森林・サバンナが広がる。
- 他の天体でも、両端で陸海・植生・氷が同じ向きに変わる。

## 計算時間
スライダーを止めてから0.15秒後（離した時は即時）に1回計算する。ソフト描画の試験環境で1回 **40〜90 ms**（地球40〜75、他天体50〜90）。スマホでは数倍かかる見込み。

## 限界
- 植生は気温と降水の表だけなので、冷えた高原が森林になるなど、地球の実際と違う変化が出ることがある。
- 海面0 m・14℃以外の値には教師が無く、正しさは確かめられない。
