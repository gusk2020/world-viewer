# Anti-KyTerra（アンティ・キテラ）— 初回試作

現在の地球条件を固定し、**氷なしの岩盤**で気候を計算して、**氷ゼロ**から氷床を育て、現在の地球と比べる試作。
既存アプリとは独立した画面です（既存画面への統合はしていません）。

- 画面：`anti-kytera/index.html`（地球儀。変数＝気温/降水/陸氷、表示＝モデル/教師/差、計算＝初回/修整後/参考）
- 結果と未達点：`RESULTS.md`
- 手法・出典・ライセンス：`METHODS.md`
- 計算コード：`model/`（Python。長期計算は開発環境で実行済み、スマホは結果表示のみ）
- 表示データ：`results/`（`display.json`, `fields.bin`, 比較図 PNG）
