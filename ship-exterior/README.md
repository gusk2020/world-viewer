# dT/dt過速世界 恒星間宇宙船 — 外観3Dモデル

利用者の既定設定(2026-11-28 の会話で受領)をもとに、手続き生成で作った外観モデル。
`index.html` はスマートフォンで回転・ズームできる表示ページ(three.js 0.185.1 を jsDelivr から読む)。
同じ内容は Claude のアーティファクト https://claude.ai/artifact/K3ZVgZjASEjZke7XYJXYbL にも公開(非公開設定)。

関連: 船内の設計は `ship-designer/`(別ブランチ `ccr-2bdf1ec2-w2o65c`)。こちらは外観だけを扱う。

## ファイル

| パス | 内容 |
| --- | --- |
| `ship.js` | 形状の唯一の定義。`buildShip(mode)` が `cruise` / `open` / `decel` の THREE.Group を返す。単位は km、船首が +X |
| `models/*.glb` | `node export_glb.mjs` で書き出した GLB(各 8〜10 MB)。材質名は `scale_hull` / `shield_silver_rough` / `thruster_black_heavy_metal` / `fusion_glow` / `thruster_hole` |
| `index.html`, `img/` | 表示ページと、その中の画像 |
| `ai-images/` | fal.ai で写実化した画像の原本と、モデル名・指示文・シードの記録(`*.meta.json`)。**変更前(v1)の形状から作ったもの** |
| `render.html`, `render.cjs` | Playwright で各視点を描画する道具(`node render.cjs views.json`、出力は `renders/`) |
| `cover_test.mjs` | 展開時の装甲葉が前方投影で隙間なく埋まるかを光線で数える検査 |
| `i2i.py`, `ctrl.py` | fal.ai の画像変換(FLUX dev image-to-image / FLUX.1 Depth pro)を呼ぶ道具 |

再生成: `npm install` のあと `npm run glb`(GLB)、`npm run cover`(隙間検査)。

## 既定設定と仮設定

既定(ユーザー設定): 居住区円筒 内径7.0 km・長さ77.0 km、非回転中心軸 直径約200 m、巡航時シールド径=円筒径の120%・展開時150%、減速時5〜7倍、
船尾は前方が小さく後方ほど大きい球状コブの群生、最後端に最大級コブ約10個・その約半数に推進器、全体で約100基、
稼働中推進器は円錐形100基で幾何学的配置、建造中・解体中の推進器は穴のみ、
質感は 側面=灰緑のスケイル / シールド=やや白銀のざらついた面 / 推進器=漆黒の重金属・稼働中は内部に核融合パルス発光、
展開時の装甲葉は並びランダムかつ前方投影で隙間なし。

仮設定(可視化のため。`SPEC` に明記): 外殻厚300 m(外径7.6 km)、減速時シールド6倍、シールド長14 km、船尾区画16 km、
隙間0.8 km、首(構造帯)の径=外殻径の84%、くびれ6か所、ヒダ40本、
大型コブは正十角形の環(1つおきの5個が稼働)、推進器は1コブ20基(中心1+環6+環13)、
建造中・解体中は「各100個」と解釈し、稼働中コブ1個の前方に小さめのコブ2個(建造中・解体中)×20穴、
減速時は稼働中の推進コブ群を傘の前面へ移設(位置は仮)。

## 検証結果(2026-11-28)

- 寸法: 全長 約109 km(巡航)/ 約113 km(減速)。
- 光線検査(5,040本): 展開時 外径=外殻径の151%・隙間0、閉時 121%・隙間0。
- 個数: 稼働中推進器100、穴200(`buildShip().userData`)。
- 表示ページ: 412×892 の画面幅でエラーなし・横スクロールなし(Playwright、three.js をローカル配信に差し替えて確認)。
- 未確認: Pixel 7a 実機での表示と操作感。

## 画像生成のメモ

- 写実化は「3Dモデルの描画 → FLUX dev image-to-image(強さ0.35〜0.5)」が形を最もよく保った。強さを上げると船尾のコブ群が消える。
- FLUX.1 Depth pro は輪郭の比率は保つが、コブや装甲葉が別物になった。
- FLUX dev の出力の商用利用可否は解釈が割れているため、製品に使う前に確認すること。
