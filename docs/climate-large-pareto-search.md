## 6. 既知良好との比較(§10)

| | 既知良好(小規模探索) | 今回の前線 |
| --- | --- | --- |
| Teacher A | 54.4% | 55.4〜58.5% |
| Teacher B | 19.3% | 14.1〜19.4% |
| 陸氷 | 63% | 65.3〜70.3% |
| 海氷 | 53% | 54.0% |
| 季節性クラス | 17 | 2.2〜15.7 |
| 経度構造 | 27% | 24.0〜27.0% |

**判定: 「実質改善なし」ではなく「同じトレードオフ曲線の上で、既知良好の
近傍がわずかに改善された」。** 質的に新しい領域は見つかっていない。

具体的には、前線最下段(Teacher B最大、季節性15.7)は既知良好とほぼ同じ運用点で:
Teacher A **+1.0**、陸氷 **+2.6**、海氷 **+0.7**、季節性は **-1.3** とわずかに後退、
経度構造はほぼ同じ。**別の探索(4shard・13,574試行、既知良好を生んだ小規模
探索2000試行とは別実行)が独立に、ほぼ同じパラメーター領域
(s≈24.3、itcz≈29〜30)へ収束した**——これは既知良好が偶然の産物ではなく、
実在する局所最適であることの追認でもある。

前線の反対側(Teacher A最大、+4.1ポイント)は季節性を2.2まで犠牲にする
——これは「新しい良い領域」ではなく、既知の「季節を弱めるとTeacher Aが
上がる」というトレードオフの延長線上にあるだけである。

## 7. 代表候補(最大4件→3件)

`Teacher A/B以外の値を新しい隠れ総合点へ合成していない`——選定方法を明記する。

- **A(Teacher A最大)**: 前線でTeacher Aが最も高い一点、単純に選ぶ。
- **B(Teacher B最大)**: 同様にTeacher Bが最も高い一点。
- **C(knee/balanced)**: 前線を(A, B)それぞれ0〜1に正規化した空間で、
  理想点(前線内のA最大値, B最大値)への**ユークリッド距離が最小**の点。
  Teacher A・Bの2値だけを使い、他の指標(植生・乾燥地・地域一致など)は
  選定に一切関与しない。
- **D(robust)**: knee近傍5件の中で、knee候補Cに対しTeacher A/Bを
  0.01ポイント以上犠牲にすることなく、地域一致・季節性クラス・経度構造の
  **3診断すべてで同等以上**(かつ少なくとも1つで真に上回る)候補を探索。
  該当なし——**Cとほぼ同一のため省略**(3件に統合)。

## 8. パラメーター収束

前線13件をパラメーター空間で見ると、**明確に二つの塊**に分かれる
(A側=季節弱め・B側=季節強め)。単純なmin/max/meanでは見えない構造なので、
両クラスタを分けて報告する。

### Aクラスタ(A>57.8、5件、季節s≈16〜20)

| パラメータ | 範囲 | 所見 |
| --- | --- | --- |
| `seasonalSensitivityC` | 16.3〜19.6 | 探索下限15のすぐ上。この領域では季節性クラスが2.2〜3.7とconstraintの下限(2%)ぎりぎり |
| `itczLandPullDeg` | **二極化**: 15.0/16.2 と 26.2/27.7/28.6 | ほぼ同じ(A,B)を全く違うITCZ引きが与える——この季節強度ではITCZの効果自体が弱いため(`tanh(季節振幅/20)`でスケールされる既知の仕組み)、パラメータが実質どこにあっても結果が変わらない |
| `snowBalanceWeight` | **全件0.20(探索下限に張付)** | この領域では陸雪氷収支の重みを下限より下げたがっている可能性がある。ただし季節性が下限ぎりぎりの領域なので、独立した信号というより「季節が弱い領域全体の副産物」の可能性が高い |
| `snowSummerMeltC` | 0.0(2件、監査の上限=氷点にちょうど張付) / -1.4〜-2.4(3件) | **監査が閉じた境界(氷点0°C)に正確に張り付いている**。ここを超えて偽融点側へは一歩も出ていない——ガードが機能している証拠であり、退化ではない |

### Bクラスタ(B>18.2、8件、季節s≈24.3〜24.5)

| パラメータ | 範囲 | 所見 |
| --- | --- | --- |
| `seasonalSensitivityC` | **24.3〜24.5(標準偏差0.1未満)** | 既知良好(24.2)を独立に追認する、非常に強い収束 |
| `itczLandPullDeg` | **29.0〜30.0(探索上限30に張付)** | 「もっと強いITCZを使いたい」という信号。今回は探索範囲を広げない方針のため据え置くが、**次回範囲拡張の最有力候補** |
| `snowBalanceWeight` | 0.65〜0.90 | 上限寄りだが張付ではない |
| `snowSummerMeltC` | -14.1〜-25.3 | 監査の上限(0°C)から十分離れている——境界の影響なし |
| `seaIceMeltDegreeDay` | 0.43〜0.56 | このクラスタ内で比較的タイトに収束 |
| `seaIceBalanceRequired` | -0.19〜-0.50(探索の両端に触れる) | 前回の実験docが記録した「meltRateとrequiredのridge(尾根)」——1つの値に決まらず、互いに補い合う関係が今回も再現された。退化ではない |

**今回は探索範囲を広げていない**(指示どおり)。`itczLandPullDeg`の上限張付は
次回の再探索で範囲を[15,40]程度へ広げる価値がある候補として記録するに留める。

## 15. 結論

**質的に新しい気候パラメーター領域は見つからなかったが、既知良好の
トレードオフ曲線をより広く・より正確に(step=1で)描き出し、その近傍で
小さいが実在する改善(Teacher A +1.0、陸氷 +2.6、海氷 +0.7)を確認した。**
`itczLandPullDeg`が探索上限30に張り付いたことは、次に範囲拡張を検討する
価値がある具体的な手がかりとして記録する。退化解(季節消失・ITCZ消失・
氷消失・偽融点・大量誤氷)は前線のどこにも再発しなかった。

次に何を判断すべきか:
1. 代表候補(A/B/C)のいずれかをworld configのdefaultへ適用するか、
   現状(既知良好のまま)を維持するか
2. `itczLandPullDeg`の探索範囲拡張([15,30]→例えば[15,40])を伴う
   再探索を行うか
3. 上記「今回追加しなかった機構」のいずれかに着手するか
