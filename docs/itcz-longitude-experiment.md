# 経度依存ITCZ — 設計・実装・評価

`docs/climate-model-diagnosis-after-stage7_5.md`（この模型は実質「緯度だけの
モデル」だという診断）と `docs/teacher-b-climate-structure.md`（季節を見られる
第2教師）に続く実験。今回追加した気候機構は**ITCZの位置が経度によって南北に
動く仕組み、ただ一つ**である。気圧場・海流・完全Köppen・月別気候は追加していない。

安全復元点：**`safe-v0.8-teacher-b`**（commit `7c7a690`、この作業の直前の状態）。

## 1. 独立設計した考え方

World Orogen が経度依存ITCZを持つことは先行調査で確認済みだが、GPLv3 のため
**ソースも数式もアルゴリズムの逐語再現も一切参照していない**。使ったのは
「観測気候分類を教師にする」「ITCZを経度ごとに動かす」という一般的な発想だけで、
中身は気象学の一般原理から独立に設計した。

原理は一文である：

> **収束帯は暖かい側へ引かれる。そして季節で温度が大きく変わるのは陸だけである。**

したがって各経度について、

1. 帯の帯状（zonal）位置の近くにある**陸**を、
2. 帯に近いほど重く（緯度方向のガウス窓 `itczPullRangeDeg`）、
3. その緯度自身の年較差が大きいほど重く（既存の `seasonWeight`）、
4. 標高が高いほど重く（`itczElevationPullM`。薄い空気は速く暖まり速く冷える）

足し合わせ、**同じ重みで割る**。出てくるのは「その経度の“効く窓”のうち何割が
季節的に振れる陸か」という 0〜1 の量で、これを

```
変位(経度) = itczLandPullDeg × tanh(その世界の最大年較差 / 20℃) × 平滑化(陸の割合)
```

だけ、**その半球の夏の側へ**動かす。符号は季節（暖候期/寒候期）が決め、
経度は一切入力にならない。大陸を動かせば帯も一緒に動く。

### 経度そのものを原因にしていないことの担保

- 式に経度・座標範囲・地名・地球専用maskは現れない。入力は `isSea` と
  `landHeight` と緯度だけである。
- 経度方向は**円環ガウスで平滑化**（`itczSmoothDeg`）し、±180° をまたいで
  連続にしてある。合成テスト6で、世界を経度180°回転させると変位場も
  ぴったり180°回るだけ（最大差 0.00e+0 度）であることを確認した。

### 帯を動かすと何が起きるか — ここが本題

変位を計算しただけでは意味がない（§9）。実際に既存の因果連鎖へ入れてある：

- **上昇・下降域が経度ごとに動く**：収束の値をセルごとに計算し直す。
- **下層風が向きを変える**：`flow = −sin(π(緯度−帯位置)/セル幅)` の符号は、
  帯がその緯度を跨いだ経度で反転する。つまり**大陸から吹いていた貿易風が、
  海から吹く風に変わる**。これがモンスーンの実体であり、湿気移流の向きが
  変わるので、海→陸の水蒸気輸送が実際に強くなる。
- そこから先は既存のまま：移流 → 陸地湿潤度 → `classifyPoint` → 植生・気候分類。
  植生を直接緑にしたり、地域別に湿潤度を足したりは一切していない。

風の**曲がり方**（コリオリ）は触っていない。`turn` は緯度と自転だけの関数の
ままなので、自転方向を反転すれば偏向は反転し、帯の熱的な位置は反転しない
（§7）。合成テスト4で数値確認した。

### 一度失敗して直した設計 — セル全体を動かしてはいけない

最初の版は位相をそのまま平行移動した。結果は測定で明確に否定された：
アフリカ上空で帯を14°北へ動かすと、**下降域も28°→42°へ一緒に動き、サハラの
暖候期湿潤度が 0.275 → 0.570 と倍増**した。地球最大の砂漠を湿らせる模型は
話にならない。Stage 7.5 の最初のモンスーンが失敗したのと同じ形である。

実際の循環セルはそう動かない。上昇域は太陽をよく追うが、極側の縁は自転が
決めるのでほとんど動かない。そこで変位に `cos²(π·offset/(2·セル幅))` の
テーパーを掛け、**セルの縁でちょうど0になる**ようにした。新しいパラメーター
は不要で、緯度→位相の写像が単調であり続けるよう `|変位| ≤ 2·セル幅/π` で
内部クランプしてある（これを超えると1行に帯が二重に折り畳まれる）。

テーパー後の同じ測定：**インドシナ 28% → 66% 植生（教師74%）に対し、
サハラは 0% → 0%、暖候期湿潤度 0.275 → 0.287**。Stage 7.5 が一度も達成
できなかった「モンスーン沿岸と砂漠の区別」が初めて出た。

## 2. 追加パラメーター（4個、すべて empirical）

| 名前 | 既定 | 範囲 | 意味 |
| --- | --- | --- | --- |
| `itczLandPullDeg` | **0** | 0–30 | 季節的に振れる陸で完全に埋まった経度が、帯を自分の夏半球へ何度引くか。**0 でこの機構は完全に切れる** |
| `itczPullRangeDeg` | 30 | 5–60 | 帯からどこまでの陸を感じるか（緯度方向のガウス窓の半値幅） |
| `itczSmoothDeg` | 20 | 2–60 | 経度方向の平滑化幅。海岸線で帯が階段状に折れないための物理的平滑化 |
| `itczElevationPullM` | 6000 | 1000–40000 | 高地が効きを増す度合い（陸が二倍に数えられる高さ）。上限側で実質オフ |

`ITCZ_SEASON_REFERENCE_C = 20` はパラメーターではなく**単位**である。
`REFERENCE_DAY_HOURS` が自転に対して果たしているのと同じ役割で、
「十分に季節のある地表」がどれくらいかを言っているだけ。

**既定を 0 にしたのは意図的**である。これにより

- 既存の保存済みプリセットは、この機構を知らないまま**従来と1bitも違わない**
  絵を描き続ける（§10 の互換要件）。
- A/B 比較が完全に対照実験になる。

## 4. A〜E：機構が本当に生きているか

`itczLandPullDeg` を変えたときの、ITCZ変位・経度方向の構造・両教師：

| 条件 | ITCZ変位 max | 経度成分 | Teacher A | Teacher B |
| --- | --- | --- | --- | --- |
| A/B 機構OFF | 0.0° | 19.1% | 63.37% | 10.22% |
| C 弱 pull=8 | 1.2° | 19.0% | 63.29% | 10.21% |
| D 中 pull=15 | 2.3° | 19.0% | 63.24% | 10.19% |

## 6. モンスーンON/OFF差 — 旧パラメーターは依然として不活性

`monsoonStrength` を 0 と 2 で比較（§12）：

| 条件 | Teacher B (m=0) | Teacher B (m=2) | 差 |
| --- | --- | --- | --- |
| 旧: ITCZ OFF, s=4 | 10.22% | 10.34% | +0.12 |
| 新: ITCZ 25, s=4 | 10.17% | 10.29% | +0.12 |
| 旧: ITCZ OFF, s=25 | 17.63% | 17.75% | +0.12 |
| 新: ITCZ 25, s=25 | 18.03% | 18.14% | +0.12 |

**変わらなかった。** 理由ははっきりしている：`monsoonStrength` は移流の到達
距離を `seasonWeight[y]`（行ごとの量）で伸縮させる**帯状の**項なので、経度
依存の帯を入れても帯状のままであり、経度方向の情報を持たない。

ただし**モンスーンという現象そのものは出た**。同じことを「暖候期と寒候期の
湿潤度の差」で測ると：

| 地域 | 旧 (ITCZ OFF) | 新 (ITCZ ON, s=25) |
| --- | --- | --- |
| インドシナ | +0.002 | **+0.314** |
| 華中・華南 | +0.000 | +0.004 |
| インド | +0.000 | +0.053 |
| サハラ | +0.000 | +0.021 |
| 米中西部 | −0.001 | −0.001 |

つまり旧パラメーターを生き返らせたのではなく、**別の経路（帯の移動と風の
反転）でモンスーンを作った**。0.1ポイントより明らかに大きい変化という §12 の
期待は、Teacher B の総合では満たさず（+0.4）、季節性クラス（0→5.1、Pareto端で
16.5）と地域の季節振幅（+0.002→+0.314、157倍）では明確に満たしている。

- 悪化：**0–15°N のアフリカ**（0–30°E: 76.0% → 24.4%、−30–0°E: 78.5% → 38.4%）。
  帯が北へ動いてサヘル帯を湿らせた。**ただしここは教師側の弱点でもある** —
  Teacher A の植生/乾燥地は乾季の衛星写真の色で決めており、Stage 5 の時点で

  緑になる。言い訳にはしないが、この −51.6 をそのまま模型の誤りとして読むのは
  正しくない。
- 改善：**−15–0°S のアフリカ/インド洋**（+24.4）、**オーストラリア北部・

0 に落ちてしまう。現実の東アジアモンスーンはハドレー循環の外まで及ぶが、
それは今回の一機構では表現できない。正直な限界として記録する。

**成功寄り**（§22 の判定基準に照らして）：

複数が成立しているので、**次の大規模探索へ進む価値はある**と判断する。
ただし条件がある：この機構の効きは季節強度に比例し、季節を強くすると
Teacher A の雪氷が崩れる。**融解の温度上限（Stage 7.5 が特定済み）を先に
入れないと、大規模探索は「季節を弱くする」解に落ちる**。そこは今回実装して
いない。

### 今回は実装していないが、次に候補となる別機構（名前だけ、§16 の指示どおり）

   モンスーンは、帯の移動だけでは表現できない。今回テーパーで諦めた部分。
